# Fictional Talent Workbench

This data-free example demonstrates all Workbench Extension Plugin v1 contribution types without
claiming to represent a real game. Install it from the bundled example workspace:

```bash
cd examples/虚构技能工作区
kt plugin add-path talents ../plugins/fictional-talent-tree
kt web
```

Open `组合模型.kirin`; its Preview selects the higher-priority “天赋树” renderer. The iframe can
receive the validated document projection, navigate to a host-approved source location, and request
evaluation of an existing validated output. It cannot access the host DOM, session token, workspace
files, Package mutations, or the network.
