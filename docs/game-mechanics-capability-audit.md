# 游戏机制计算能力边界

本页说明 Kirin Tor 对常见理论计算问题的适用范围。它不是游戏数据文档，也不证明任何真实游戏的
系数或规则正确。

## 结论

Kirin Tor 可以计算作者明确声明的有限公式、有限分布和有界 Process。Process 在有限、可重放的
Scenario 中组合状态、精确时间、事件、动作、flow、约束、Measure 与 Objective；内核不理解生命、
资源、技能、天赋或敌人等游戏概念。

“给定模型可以计算”不等于“工具能从规则说明自动生成正确模型”。作者仍负责事实、理想化假设、
事件顺序、目标函数和评价标准。

## 已证明可表达的机制形状

| 机制形状 | Kirin 写法 | 能力边界 |
| --- | --- | --- |
| 概率加权期望 | 精确表达式或有限分布 | 不做隐式抽样 |
| 阈值、分段、封顶 | `if_else` / `piecewise` / `min` / `max` | 单位和值域保持检查 |
| 有限重复 | 常数边界 `sum` / `product`，或 Process 事件链 | 动态重复必须消耗显式 fuel |
| 时间与路径依赖状态 | Process state、event、phase、`next`、flow | 同 phase 批次读取同一快照并同时提交 |
| 资源、冷却、顺序充能 | 普通 state、guard、schedule、key、flow | 没有游戏专用合同 |
| 延迟池、清除、自疗 | 普通数值状态、事件与 output event | 已由酒仙理想场景端到端验证 |
| 固定或条件策略 | Scenario Policy、事件后/条件穿越决策 | 固定策略选到不可用动作会失败 |
| 连续释放时点 | 有界连续 decision occurrence | 当前一般搜索只给 `best_found` |
| 有限随机路径 | Process branch | 完整枚举后计算逐路径 Measure 与严格输出期望 |
| 可达、稳态、周期 | Process `reach` / `steady` / `cycle` Analysis | 只接受满足相应证明前提的有界模型 |
| 多方案与多目标 | Scenario variant、Measure、Objective | 每个 variant × objective 独立优化并返回全部并列最优 |
| 轨迹与策略权衡图 | Analysis 多 chart | run/compare/optimize/reach/cycle 轨迹和搜索图都是只读投影 |
| 多层静态属性 | 封闭 `type` 对象 | 未知或缺失属性失败 |
| 查表、扫描与符号计算 | table、scan、grid、solve 等 | 继续使用静态数学引擎 |

六类动态纸面模型覆盖多资源与充能、伤害延迟池、可刷新 DoT/HoT、吸收盾、有限层数 Buff 和显式
独立/相关随机触发。它们验证通用原语的表达能力，不证明任何真实游戏规则。

## 必须显式选择的模型边界

- “平均伤害作为确定事件”只是代表性平均场景；它不同于对每条有限随机路径先计算输出再取期望。
- 血线波动可以是极差、最大回撤、总变化量、方差或低血线持续时间；必须由作者定义 Measure，内核
  不替作者选择。
- `decide every` 是作者主动声明的时间网格。自由时点搜索不会静默取整或套用隐藏步长。
- `exact_global` 只用于已完整证明的模型范围；当前一般连续搜索记录容差与预算并标记
  `best_found`。方法、容差、预算和未使用的近似项贯穿请求、结果与运行记录。当前没有会产出
  `global_with_error_bound` 的一般求解器。
- `steady` 需要有限可枚举状态；`cycle` 需要确定场景并实际发现精确重复状态；否则明确拒绝。

## 作者与 Agent 协作边界

Agent 可以作为普通本地创作工具，把作者给出的规则、假设和决策问题写入
`entries/**/*.kirin`；打开的工作台会自动发现新文档，并在没有本地未保存草稿时重新加载外部修改。
这减少的是录入和维护成本，不扩大可计算机制的集合，也不证明输入规则真实。

Agent 不会成为 Process 中的隐式行动者，不能从游戏术语补全事件、顺序、概率、目标函数或数据来源。
工作台也不展示 Agent 活动记录，并且不把 Agent 的自然语言推理保存成另一份模型。若浏览器中已有
未保存草稿，外部修改进入显式冲突比较而不是覆盖草稿。完整合同见
[浏览器工作台规范](web-workbench.md#external-agent-authoring)。

## 明确非目标

- 动态目标或效果实体集合、选敌、距离、移动和位置；
- 真实战斗日志、服务器事件顺序、网络延迟和技能队列；
- 完整职业优先级模拟或内核自行推荐天赋；
- 无边界连续优化，或没有证明却声称全局最优；
- 从字段名称猜测资源、冷却、生命或其他游戏意义；
- 从游戏服务器、网站或日志自动同步技能、天赋、等级系数、热修和版本数据。

需要这些能力的问题必须先由作者裁剪为有限理想场景，或留给范围更合适的外部工具。Kirin 只对
写入 `.kirin` 的模型、边界和来源负责计算与重放。
